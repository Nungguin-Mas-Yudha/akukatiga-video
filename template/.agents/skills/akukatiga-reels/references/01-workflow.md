# Stages and gates

| # | Stage | In, out | Gate before the creator sees anything | Pattern |
|---|---|---|---|---|
| 1 | Script | the creator's transcript → `script.txt` | the script the creator gives is done and taken as true: never fact-check or re-verify it | `references/02-script-and-caption.md` |
| 2 | Voice + caption | script → `voice.mp3` (+ `voice.alignment.json` when the voice is ElevenLabs: exact word times; another provider through `node scripts/narrate.mjs --root ../.. --config reels/<slug>/voice.json --text-file reels/<slug>/script.txt --out reels/<slug>/voice.mp3`, then align.py times it by speech recognition) → `caption.txt` → `node ../../scripts/py.mjs scripts/align.py <slug>` → `words.json`. Mechanical: Haiku runs it | the creator chose the voice; never splice a take, regenerate it whole; `node ../../scripts/py.mjs scripts/check.py plan <slug>` exits 0; every "!" line from align resolved | same, and `references/06-workspace.md` (The voice) |
| 3 | Treatment + plan (one page) | caption → `treatment.md` (the concept, the thread object, the `HANDOFF` table, two plant-and-payoff pairs, the one big move, 3-5 hook ideas in one line each) and `plan.md`: **one line per beat** (every key word, at most 1.2 s apart): actor, place, trigger word → event, angle, camera cause, "2.5D: how". Three options only for the hook | **the creator picks the hook and approves treatment and plan in words before any pixel.** Every beat has an actor in a place; no two scenes in a row share a framing | `references/12-treatment.md`, `references/03-sentence-to-picture.md`, `references/14-shot-recipes.md`, `references/object-references.md` |
| 4 | Assets | the approved `plan.md` → every picture the plan needs, gathered **before composition starts**: one reference and one licence row per physical object in `references.md`; a plate, a cut-out, and its states (the ghost view) saved flat in `assets/` (`plate-lab.jpg`, `tank-cutout.png`, `tank-ghost.png`); a logo or footage from `scripts/logos.mjs` / `scripts/footage.mjs`; a code-drawn object only when parts must move (`13-mockups.md`) | no scene starts with a missing picture: every object that appears has its reference and licence row, every file name says what the object is; nothing on screen is an AI image (creator decision 2026-10-29) — generation is for mood reference only, kept in `assets/_source/`; a picture that must rotate or show real metal is a hybrid shot, not a stretched flat one | `references/11-image-assets.md`, `references/object-references.md`, `references/09-three-d-look-and-plates.md`, `references/13-mockups.md` |
| 5 | Composition | `assets/` + `plan.md` → the scenes in `compositions/reels/` or `compositions/landscape/`, one file per scene, registered by `index.tsx`. Two passes: the hardest 8-12 s first, alone, and it is also the styleframe (no separate storyboard round); then the rest, one builder at a time | pass 1: every object laid beside its reference; `check.py render` exits 0 (pace, hold, motion, detail, tone, flashes); one Opus reviewer who did not build it reads `check.py compare`, FAIL lines only; the creator accepts it before anything else is built. pass 2: machine checks per scene; the creator watches the browser preview with sound and marks each scene `belum direview`, `revisi` or `disetujui`; no per-scene MP4 for curation; one combined reviewer pass after the full draft, round 2 on changed scenes only | `references/04-motion-and-sync.md`, `references/10-storyboard-and-qc.md`, `references/14-shot-recipes.md` |
| 6 | Sound + deliver | picture accepted → loudness, then `node render.mjs <slug>` → `engine/full-visual/output/YYYY-MM-DD/NN-<slug>.mp4`, caption `.txt`, copied to `workspace/output/<project folder>/<slug>.mp4` with `caption.txt` (the post caption) and `cover.jpg` (a frame of the video), full paths printed (`references/06-workspace.md`) | loudness about -14 LUFS, true peak at most -1 dBTP; both checks exit 0 on the final file | |

Assets and composition are separate stages. Assets is the step that gathers pictures; composition is the step that
puts them on the timeline. A scene that discovers it needs a picture stops and goes back to stage 4 — it does not
grab one mid-build.
