# Stages and gates

| # | Stage | In, out | Gate before the creator sees anything | Pattern |
|---|---|---|---|---|
| 1 | Script | the creator's transcript → `script.txt` | the script the creator gives is done and taken as true: never fact-check or re-verify it | `references/02-script-and-caption.md` |
| 2 | Voice + caption | script → `voice.mp3` (+ `voice.alignment.json` when the voice is ElevenLabs: exact word times; another provider through `node scripts/narrate.mjs --root ../.. --config reels/<slug>/voice.json --text-file reels/<slug>/script.txt --out reels/<slug>/voice.mp3`, then align.py times it by speech recognition) → `caption.txt` → `node ../../scripts/py.mjs scripts/align.py <slug>` → `words.json`. Mechanical: Haiku runs it | the creator chose the voice; never splice a take, regenerate it whole; `node ../../scripts/py.mjs scripts/check.py plan <slug>` exits 0; every "!" line from align resolved | same, and `references/06-workspace.md` (The voice) |
| 3 | Treatment + plan (one page) | caption → `treatment.md` (the concept, the thread object, the `HANDOFF` table, two plant-and-payoff pairs, the one big move, 3-5 hook ideas in one line each) and `plan.md`: **one line per beat** (every key word, at most 1.2 s apart): actor, place, trigger word → event, angle, camera cause, "2.5D: how". Three options only for the hook | **the creator picks the hook and approves treatment and plan in words before any pixel.** Every beat has an actor in a place; no two scenes in a row share a framing. References for each physical object are fetched after approval, per scene, as the builder reaches it, into `reels/<slug>/references.md` | `references/12-treatment.md`, `references/03-sentence-to-picture.md`, `references/14-shot-recipes.md`, `references/object-references.md` |
| 4 | The hardest passage | the hardest 8-12 s built first, alone; it is also the styleframe (no separate storyboard round) | every physical object laid beside its reference (`references/object-references.md`, The check); `check.py render` exits 0 (pace, hold, motion, detail, tone, flashes); one Opus reviewer who did not build it reads `check.py compare`, FAIL lines only; then the creator sees it. Nothing else is built until the creator accepts it | `references/04-motion-and-sync.md`, `references/10-storyboard-and-qc.md` |
| 5 | The rest | remaining scenes, one builder at a time (Opus, owns whole scenes) | machine checks per scene; one combined reviewer pass after the full reel draft, then changed scenes only in round 2 | same |
| 6 | Sound + deliver | picture accepted → loudness, then `node render.mjs <slug>` → `engine/full-visual/output/YYYY-MM-DD/NN-<slug>.mp4`, caption `.txt`, copied to `workspace/output/<project folder>/<slug>.mp4` with `caption.txt` (the post caption) and `cover.jpg` (a frame of the video), full paths printed (`references/06-workspace.md`) | loudness about -14 LUFS, true peak at most -1 dBTP; both checks exit 0 on the final file | |
