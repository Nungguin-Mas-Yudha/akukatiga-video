# 1 — Script

**Gerbang mesin**: `node ../../scripts/py.mjs scripts/check.py stage <slug> 1` — harus `exit 0`.

**Tujuan**: satu naskah yang dibacakan, dari cerita creator atau topik yang sudah disetujui.
**Masuk**: transkrip, brief, atau topik. **Keluar**: `plans/script.txt` (satu file per format kalau dua
format: `script-reels.txt`, `script-landscape.txt`), `plans/sources.md` kalau ada klaim.

**Gerbang**: naskah dari creator diterima apa adanya — jangan riset ulang isi naskah. Kalau naskah dibuat
dari topik, setiap klaim punya sumber atau ditandai belum terverifikasi.

**Baca di folder ini**

| File | Untuk |
|---|---|
| [`script-and-caption.md`](script-and-caption.md) | format naskah + caption reels, satu baris per blok |
| [`script-recipe.md`](script-recipe.md) | resep naskah 16:9: 3.000-3.800 kata, 150-160 kata/menit |
| [`script-qc.md`](script-qc.md) | pemeriksaan naskah 16:9 oleh reviewer + fact checker |
| [`script-and-research.md`](script-and-research.md) | riset dan outline 16:9: klaim, dua sumber, kutipan bukti |
| [`research-lanes.md`](research-lanes.md) | jalur riset reels: satu cerita nyata, 60-120 detik |
| [`journal-sources.md`](journal-sources.md) | berkas jurnal, angka, dan batas lisensi gambar |
